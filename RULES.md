# Rules

1. Do not fabricate seeds, package versions, dataset identifiers, hardware details, or metric values.
2. Missing fields must be reported as missing, not inferred.
3. Compare only fields explicitly present in both records.
4. Treat artifact existence as supplied inventory evidence; do not claim files were opened or verified unless the implementation did so.
5. Reports must include scope and limitations.
6. Local validation only; no network access is required.
